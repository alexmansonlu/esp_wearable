### 4.0 先讲两个共同概念（5 分钟）

**ADC（模数转换）**：传感器给出的是 0–3.3 V 的连续电压，ESP32 把它量化成 0–4095 的整数（12 位）。`setup()` 里三行就是在配置这件事：`analogReadResolution(12)` 与 `analogSetPinAttenuation(..., ADC_11db)`（[main.cpp:130-133](../firmware/src/main.cpp#L130-L133)）。三路模拟传感器全接 **ADC1**（GPIO32–39），因为 ADC2 在 Wi-Fi 开启时不可用。

**I2C（数字总线）**：两根线（SDA 数据、SCL 时钟）挂多个芯片，每个芯片有地址；主控按地址读写芯片内部的"寄存器"。本项目一条总线：MPU6050 @0x68、MAX30100 @0x57（[main.cpp:137-138](../firmware/src/main.cpp#L137-L138)）。

**固件的节拍**：`loop()` 不用 `delay()`，用 `millis()` 时间戳让几个任务各按各的频率跑——200 Hz 波形、50 Hz GSR、25 Hz 加速度、10 Hz 发包（[config.h:27-31](../firmware/include/config.h#L27-L31)，[main.cpp:174-245](../firmware/src/main.cpp#L174-L245)）。

AI 提示词：「读 firmware/src/main.cpp 的 loop()，列出里面有几个"定时任务"、各多少 Hz、各做什么，用一张表给我。」

### 4.2 思知瑞 GSR 皮肤电（12 分钟）

| | 内容 |
|---|---|
| 她先讲 | 它测的是什么？数值上升代表人怎么了？ |
| 机制 | 紧张 → 交感神经 → 手指汗腺分泌微量汗液 → 汗液含电解质 → 皮肤导电性上升。汗腺只受交感神经支配，所以是最"干净"的唤醒度指标，刺激后 1–3 秒可见 |
| 信号怎么到 ESP32 | 两个指套电极之间的皮肤是一个电阻；模块用分压电路把电阻变成电压（内部 2 倍放大 + 0.5–5 Hz 带通），从 `ADC` 引脚（旧批次丝印 `OUT`）输出 → GPIO34（ADC1_CH6）。**必须 3.3 V 供电**：5 V 供电时输出可能超过 ADC 上限 3.3 V。板上没有电位器，基准不可调 |
| 固件读取 | 50 Hz 任务里连读 8 次取平均（过采样降噪）→ `g_gsrRaw`（[main.cpp:200-211](../firmware/src/main.cpp#L200-L211)） |
| 预处理 | ① 50 点滑动平均 = 1 秒平滑（`MovingAverage<50>`，[main.cpp:33](../firmware/src/main.cpp#L33)，[MovingAverage.h](../firmware/src/MovingAverage.h)）；② 每秒存一点、15 点做线性回归斜率 `gsr_slope`（[main.cpp:91-102](../firmware/src/main.cpp#L91-L102)、[213-218](../firmware/src/main.cpp#L213-L218)）；③ 校准 30 秒取平均做基线，之后输出相对变化 `gsr_delta = (当前 − 基线) / 基线`（[main.cpp:234-242](../firmware/src/main.cpp#L234-L242)、[259-260](../firmware/src/main.cpp#L259-L260)）；④ quality bit1：读值在 5–4090 之间才算在量程内（[main.cpp:264](../firmware/src/main.cpp#L264)） |
| 用处 | `gsr_delta` 是五条状态规则每一条都用的量；`gsr_slope` 抓"正在紧张起来"（ARCHITECTURE §5.2）。一切用相对基线的变化量，绝不用绝对值——个体差异太大 |
| 现场演示 | 戴上指环，Serial Plotter 看 `gsr`；心算 37×23 或憋气 10 秒 → 曲线爬升；深呼吸 → 缓慢回落 |
| 追问 | 为什么读 8 次取平均？滑动平均窗口从 50 改成 5 会怎样？为什么要除以基线？ |
| AI 提示词 | 「在 firmware/src/main.cpp 里，从 analogRead(PIN_GSR) 开始，把 GSR 数值一路到写进 JSON 的每一步按顺序讲给我，每步为什么要做。」 |
| 接线 | VCC→3V3，GND→GND，ADC→GPIO34；指套线插到底（3.5 mm 插孔），套非按键手的食指与中指 |

### 4.3 PulseSensor 光电脉搏（12 分钟）

| | 内容 |
|---|---|
| 她先讲 | 它是光电还是心电？原理一句话 |
| 机制 | PPG：绿光 LED 照进指尖，心脏每跳一次指尖血容量脉动一次，血液吸收绿光，反射光强随脉搏起伏，光敏元件把光强变成电压 |
| 信号怎么到 ESP32 | 模块输出连续模拟波形 0–3.3 V → GPIO35（ADC1_CH7）。力度关键：太紧压闭血管没波形，太松漏光噪声大 |
| 固件读取 | 200 Hz 快任务 `analogRead(PIN_PULSE)`（[main.cpp:185-191](../firmware/src/main.cpp#L185-L191)） |
| 预处理：BeatDetector | 从一条波浪线到心率数字的全过程（[BeatDetector.h](../firmware/src/BeatDetector.h)）：① 慢基线扣除，去掉呼吸/漂移（第 21 行）；② 峰值包络自适应阈值：包络慢慢衰减、被新峰顶起，阈值取包络一半，且不低于 `minThreshold`（24–27 行；PPG 用 25，[main.cpp:29](../firmware/src/main.cpp#L29)）；③ 上穿触发 + 不应期 300 ms（两跳最短间隔，对应 200 bpm 上限）+ 滞回 0.7（30–39 行）；④ 逐跳间隔 IBI，只收 300–1500 ms（40–200 bpm）范围内的，其余当伪影（85–91 行）；⑤ `bpm()` = 60000 / 最近 8 个 IBI 的平均（44–50 行）；⑥ `rmssd()` = 相邻 IBI 差的均方根，≈30–40 秒窗口，是 HRV（54–64 行）；⑦ `fresh()`：3 秒内没有心跳就当信号丢失（69–71 行） |
| 用处 | `hr_p` 是游玩时统一心率 `hr` 的实际来源（ECG 那时受肌电干扰）→ `hr_delta` → 状态判断的慢速通道（30 秒窗口）；`rmssd_p` 是独立于心率的第二证据：压力上升 → RMSSD 下降 |
| 现场演示 | Serial Plotter 看波形，一次心跳一个峰；Serial Monitor 看 `{"type":"beat","src":"ppg",...,"ibi":812}` 每跳一条；用力压 → 波形变平、beat 停 → 3 秒后 `hr_p` 变 −1 |
| 追问 | 为什么阈值要"自适应"而不是写死一个数？不应期 300 ms 改成 100 ms 会怎样？为什么 IBI 超过 1500 ms 要丢掉？ |
| AI 提示词 | 「逐段讲解 firmware/src/BeatDetector.h 的 update() 函数，假设我没有编程基础，用"抓浪峰"的比喻。然后告诉我 300、1500、0.5、0.7 这几个数字各是什么意思。」 |
| 接线 | +（红）→3V3，−（黑）→GND，S（紫）→GPIO35；指尖魔术贴固定、遮光，非按键手 |

### 4.4 AD8232 心电（10 分钟）

| | 内容 |
|---|---|
| 她先讲 | 三个电极贴哪里？`lead_off` 是什么意思？ |
| 机制 | 心脏每次收缩由一次电去极化波驱动，传到体表约 1 mV。AD8232 放大约 1100 倍并带通滤波，输出 0–3.3 V 心电波形；R 峰极尖锐，逐跳间隔可精确到毫秒——HRV 的金标准 |
| 信号怎么到 ESP32 | OUTPUT → GPIO32（ADC1_CH4，模拟波形）；LO+ → GPIO27、LO− → GPIO14（数字，电极掉了输出高电平） |
| 固件读取 | 同一个 200 Hz 快任务；先查 `ecgLeadOff()`（两个 LO 脚任一为高即脱落，[main.cpp:60-66](../firmware/src/main.cpp#L60-L66)），没脱落才喂给 `g_ecgBeat`（[main.cpp:177-184](../firmware/src/main.cpp#L177-L184)） |
| 预处理 | 同一个 BeatDetector 类，只是 `minThreshold` 提高到 40 抗噪（[main.cpp:30](../firmware/src/main.cpp#L30)）——同一段代码同时服务 PPG 与 ECG，这是"抽象"的意义。**统一心率**：`bestHr()` 按 ECG > PPG > MAX30100 取第一个可信的（[main.cpp:68-89](../firmware/src/main.cpp#L68-L89)） |
| 用处 | `hr_e` 是 `hr` 的最高优先来源（静息段最准）；`rmssd_e` 是 HRV 真值，用来校验 `rmssd_p`、给 Nick 的分析提供金标准；`lead_off` 让坏数据自动被标记 |
| 现场演示 | 贴三片（胸贴法信号最好；手臂法方便但按键时肌电干扰）→ `lead_off` 变 0、出现 `src:"ecg"` 的 beat；拔掉一片 → `lead_off` 变 1，`hr` 自动切到 PPG（自检清单第 8 项） |
| 追问 | 既然有 PulseSensor，为什么还要它？游玩时为什么它会掉线？ |
| AI 提示词 | 「firmware/src/main.cpp 的 bestHr() 在做什么？如果 ECG 电极掉了、PulseSensor 也没贴好，hr 会是多少？quality 的 bit0 会怎样？」 |
| 接线 | 3.3V→3V3，GND→GND，OUTPUT→GPIO32，LO+→GPIO27，LO−→GPIO14，SDN 悬空；皮肤先酒精棉片清洁再贴 |

### 4.5 MPU6050 六轴（8 分钟）

| | 内容 |
|---|---|
| 她先讲 | 它不测情绪，为什么很重要？ |
| 机制 | MEMS：芯片里微米级的硅质量块挂在弹簧上，加速时位移改变电容，测电容换算加速度。静止时也测得到重力 1 g |
| 信号怎么到 ESP32 | 数字：I2C 地址 0x68，加速度在寄存器 0x3B 起连续 6 字节（X/Y/Z 各 16 位，高字节在前），±2 g 量程下 16384 = 1 g |
| 固件读取 | 自写最小驱动 [Mpu6050.h](../firmware/src/sensors/Mpu6050.h)：`begin()` 先探测地址（0x68 不应答就试 0x69），写 0x6B=0 **唤醒**（上电默认睡眠）、0x1C=0 设 ±2 g、0x1A=3 开 44 Hz 低通（11–24 行）；`readMotion()` 读 6 字节、拼成三轴、算合加速度、减去 1 g 重力取绝对值（29–39 行）。主循环 25 Hz 读一次，5 点滑动平均（[main.cpp:41](../firmware/src/main.cpp#L41)、[226-232](../firmware/src/main.cpp#L226-L232)） |
| 用处 | `acc` 是运动门控：`acc > 0.8g` 时状态判断冻结（ARCHITECTURE §5.3）。PPG、GSR、ECG 全都怕动作伪影——甩手 → 光电波形乱 → 假心率 → 误判紧张，它是这条链的防线 |
| 现场演示 | 静置 `acc` ≈ 0；甩手 → 明显增大；同时看 PulseSensor 波形被打乱 |
| 追问 | 为什么要减去 1 g？没有它，什么情况下游戏会误判？ |
| AI 提示词 | 「firmware/src/sensors/Mpu6050.h 里 begin() 写了三个寄存器，各是干什么的？如果不写 0x6B 会怎样？readMotion() 最后一行为什么是 mag − 1.0？」 |
| 接线 | VCC→3V3，GND→GND，SDA→GPIO21，SCL→GPIO22；戴在 PulseSensor 同一侧手背 |

### 4.6 裸 MAX30100（3 分钟，只讲不接）

| | 内容 |
|---|---|
| 她先讲 | 为什么默认停用？ |
| 机制 | 数字式 PPG 芯片，I2C 0x57 输出原始红外 / 红光强度，靠库在 ESP32 上算心率 |
| 为什么停用 | 多数廉价板的 I2C 上拉电阻接到 1.8 V 轨，直接用通信失败；要拆 3 颗电阻、外接 4.7 kΩ 到 3.3 V。`config.h` 里 `ENABLE_MAX30100 0`（[config.h:10](../firmware/include/config.h#L10)），整套代码用 `#if` 包着，关掉不影响其他传感器 |
| 用处 | `hr_m` 是 `hr` 的最低优先兜底；三种心率来源（模拟 PPG / 数字 PPG / ECG）的横向对比是报告素材 |
| 追问 | 上拉电阻是干嘛的？ |

### 4.7 收口：整机数据流（5 分钟）

投屏 HARDWARE.md §8 的映射图，再看 10 Hz 发包那一段（[main.cpp:244-284](../firmware/src/main.cpp#L244-L284)）：每个字段从哪个传感器、经过哪段处理、进了哪条规则。`quality` 三个位：bit0 有可信心率、bit1 GSR 在量程、bit2 基线就绪，全好 = 7。

一句话分工：GSR 说"现在多紧张"，心率 / HRV 说"紧张持续了没有"，ECG 保证这些数字有真值可对照，MPU6050 说"这些数据能不能信"，游戏表现说"紧张是专注还是崩溃"。
