# 硬件决策历史（为什么是现在这套）

> 记录硬件方案的演进与每次变更的原因，避免未来重新讨论已定案的问题。

## 演进时间线

| 版本 | 日期 | 方案 | 变更原因 |
|---|---|---|---|
| v0.1 | 2026-08-28 | 计划：ESP32 x2 + 裸 MAX30102 x2 + GSR + MPU6050（可选） | 初始规划（未采购） |
| v0.2 | 2026-09-03 | 实购：Gravity MAX30102(SEN0518) + GSR + Gravity LIS2DH(SEN0224) | 按第一批实际采购更新；发现 SEN0518 是板载算法黑盒：HR 每 4 秒更新、无原始 PPG → 无 HRV |
| v0.3 | 2026-09-03 | 加购：AD8232 + PulseSensor + 裸 MAX30100 | 用户问"HRV 是什么/裸版是否更好"后决定补 HRV 支线；0x57 冲突（SEN0518 vs MAX30100）用双 I2C 总线解决 |
| **v0.4（现行）** | 2026-09-03 | **移除 SEN0518 与 LIS2DH，改用 MPU6050** | 用户退掉两件 Gravity 模块；心率全靠波形检测（PulseSensor/AD8232），4 秒延迟问题消失，HRV 进主线；单 I2C 总线即可 |

## v0.4 定稿清单与角色

| 元件 | 引脚 | 角色 |
|---|---|---|
| PulseSensor | GPIO35 (ADC1) | 游戏实时心率主力（逐跳 PPG） |
| AD8232 | GPIO32 + LO± GPIO27/14 | HRV 金标准（校准段/实验段；游玩时受按键肌电干扰） |
| 思知瑞 GSR 模块（2026-09-07 核实：3 针 GND/VCC/ADC，非 Grove，无电位器） | GPIO34 (ADC1)，3.3V 供电 | 快速情绪通道（1–3 秒皮电反应） |
| MPU6050 | I2C 0x68 (GPIO21/22) | 运动门控——v0.4 全靠波形检测后，这是最关键防线 |
| 裸 MAX30100 | I2C 0x57（同总线） | 选配兜底；多数板需改上拉电阻（4.7k 到 1.8V 轨的问题），固件默认 ENABLE_MAX30100=0 |

## 已解决的技术问题（勿重新踩）

- **0x57 地址冲突**：v0.3 时 SEN0518 与 MAX30100 冲突，曾用 Wire1(GPIO25/26) 分总线；v0.4 SEN0518 移除后回到单总线
- **GSR 电压**：GSR 模块 5V 供电时输出可能超 ESP32 ADC 3.3V 上限 → 必须 3V3
- **GSR 型号误记**：文档曾一直写 Grove GSR，2026-09-07 按厂商资料核实为思知瑞 3 针模块（无电位器）；ESP32 实物为 micro-USB CH340 版而非 Type-C，引脚相同
- **ADC2 与 Wi-Fi 冲突**：三路模拟全接 ADC1（GPIO32/34/35）
- **MPU6050 上电睡眠**：固件写 PWR_MGMT_1=0 唤醒，±2g + DLPF 44Hz
- **命名澄清**（曾造成误解）：GSR 模块的 ADC 输出是皮肤电导不是"心率波形"；PulseSensor 商品名带"心电"但实为光电 PPG

## 建议补购（HARDWARE.md 第 9 节有完整表）

必备：一次性心电贴片电极（耗材！10 人次要 30+ 片）、GSR 备用指环电极、酒精棉片。
强推：轻触按钮 x2 做实验事件标记器（逐时刻 ground truth 标签，¥1 性价比之王）。
